# STS Dataset

Public dataset of Sentient Trading Society Reddit posts, comments, and reference materials, with accompanying analysis prompts.

## Provenance
STS Public Material - Our Public Education - https://SentientTradingSociety.com

JSON content: Scraped from Reddit (r/Trading, r/Daytrading, r/InnerCircleTraders and r/Futurestrading) as of 2 September 2026.

## Contents
- `data/Article-public.pdf` - dataset background and methodology
- `STS_Dataset_Prompts_and_Instructions_public.pdf` - AI/LLM prompt templates for LLM analysis
- `data/submitted-2026-09-02.json` - 391 Reddit submissions
- `data/comments-2026-09-02.json` - 251 Reddit comments

## Format
LaTeX PDFs.

JSON records, one object per row, UTF-8 encoded.
